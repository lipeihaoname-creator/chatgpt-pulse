## Windows 原生实现

- 使用 WASAPI shared-mode loopback 和默认 `eRender/eMultimedia` 播放端点；不打开麦克风，不需要 Stereo Mix、虚拟声卡、FFmpeg 或常驻外部服务。
- 采集、COM 初始化和释放都在专用工作线程。类型显式保持线程归属，没有 `unsafe Send/Sync`。结束时先停止并释放捕获/设备接口，再关闭事件并匹配 `CoUninitialize`。
- 使用设备真实 mix format；支持 float32/64、PCM 8/16/24/32、extensible 有效位深、块对齐和多声道平均。非有限样本变为零并限制范围。压缩/未知子格式明确拒绝。
- 每个完整数据包及时读取与释放，正确跳过 SILENT 指针；不连续或时间错误标志清理分析状态。事件等待与每次排队处理有界，分析约 25Hz。原始 PCM 仅在内存处理，读后清零，不进入前端、数据库或网络。
- 默认设备标识每秒核查一次；设备失效、资源失效、服务异常或较长暂停释放旧流并重新枚举。失败采用最高约 8 秒的有限退避，关闭开关或退出能打断等待；不是高频重试。
- Windows 正常无包静音不触发 Mac 的 8 秒回调超时。未收到声音不能证明受保护音频可采集；界面如实说明系统混音范围与限制。
- 音乐采集最低 Windows 10 1703（15063）；更早系统只禁用音乐。其余程序原有平台边界保留。Windows-only 新增直接依赖为已锁定、已有缓存的 `windows = 0.62.2` 与 `windows-version = 0.1.7`，许可沿用上游 MIT/Apache 等条款，无全局工具安装或依赖全面升级。
- 主窗口按低频接收状态，悬浮窗接收有序特征；轮次、序号和过期保护保留。隐藏/最小化不继续绘制，失焦但原生仍可见时允许正常响应。附加 16 逻辑像素参与窗口尺寸与物理边缘约束。

## 当前桌面与安装验收状态

最初隔离桌面可运行实际 WASAPI/WebView2；实际桌面宿主均已有管理员身份，没有普通桌面令牌。尝试同账号受限权限、Medium 完整性子进程时，初始化失败 `0xC0000142`。用户随后明确允许继承现有管理员桌面身份；在此授权下完成可视及安装检查，没有触发新 UAC、改变账户/权限、系统音量、默认设备、驱动或网络设置。**独立标准用户未验证**，不把当前用户安装配置等同于此项通过。

- 实际桌面主窗口确认默认关闭；手动开启后状态显示正在响应系统播放音频，选择下缘半环、中文方案保存成功。原生探针记录真实音频驱动人物变化，窗口未聚焦仍可见且继续响应；实际 150% 缩放下窗口为 420×216 物理像素，即 280×144 逻辑像素，含频谱空间。截图只用隔离测试数据。
- 实际安装版再次启动，同一隔离数据中的下缘半环与中文方案保留、已保存的音频开启偏好自动连接。播放中通过本机设置隐藏悬浮窗，原生 `view_visible=false`、人物停绘；恢复显示后 `view_visible=true`，真实音频自动恢复人物律动。隐藏/恢复前后的原生探针随包提供。

## 未测试与限制

- Windows 10 实机、异机和独立标准用户账户；所有实际 DPI/多显示器组合。
- 默认输出的真实切换、耳机/蓝牙插拔、44.1k/48k 硬件格式变化、设备拔除、睡眠唤醒及音频服务重启。实现恢复路径不等于已做物理操作；没有为测试修改系统声音、默认设备或服务。
- 缺失 WebView2 的干净系统、真正断网电脑首次安装，以及独立标准用户账户安装/升级/卸载。中文与空格目录通过不等于中文 Windows 账号实测。
- 本轮实际证明原生可见失焦继续响应及设置隐藏/显示恢复；覆盖最小化与减少动态效果的浏览器/几何检查不能冒充全部原生桌面组合。物理左右贴边、多显示器及全部最小化组合仍需扩展人工检查。
- 当前包无代码签名，不声称 SmartScreen 或发布者未知警告已消失。音乐不识别曲名、歌词或情绪；曲线表示频谱，镜像不表示独立双声道。
- 资源采样是短时单机观察，隔离测试开启了少量测试探针，不能据此保证其他电脑 CPU、内存或长时间稳定性。
