# 头像渲染与动画

内置图集各格的构图不同。0.16.2 对整格缩放、平移，虽然外部头像容器不动，却会将图片的直底边拉进圆框，造成衣领下方断开；换整张图时，头发和下颌也会改变位置。只检查容器矩形无法发现这类内容问题。

从 0.16.3 起，每名内置角色始终使用平静表情的头发、外轮廓、下颌和衣服作为底图，统一保留足够的裁切余量。眉眼与嘴部分开遮罩，只在内部更新当前表情；眉眼遮罩完全覆盖原有眼睛，下面另做渐隐，避免混入另一个下颌。工作和空闲表情共用持续存在的图层节点，保持眨眼同步。

原有 `src/lib/portrait-registration.js` 参数只定位表情区域，不再缩小整张身体底图。图片解码完成后才成为候选目标；快速变化合并为最新目标，闭眼时旧五官退至固定底图，再显现新表情，完全显现后才睁眼。同一时间不交叉淡化两张完整头像。隐藏窗口清理过渡并保留最新目标，恢复后不补播旧表情。解码失败保留现有画面。

呼吸和姿态各用独立的内部层，只平移和旋转，不叠加缩放。点击和完成反馈共用姿态层，中断动作从当前矩阵继续。自定义头像和状态图包继续使用用户裁剪，不套用内置角色的五官合成。减少动态效果时取消过渡，显示静态表情。

原始 PNG 不改写。开发诊断 `scripts/calibrate-portraits.mjs` 输出当前图集的几何拟合记录；替换内置图集时需重新校准并检查遮罩，现有坐标不能直接套用任意人物。渲染是离散五官图片的衔接，不是逐帧面部变形或 Live2D。

`tests/portrait-body.browser.mjs` 使用实际组件和样式，在透明背景逐表情截图，检查底部关键区域的真实图像覆盖、顶部/衣领像素是否变化、五官核心是否漏出旧图、眉眼节点是否重建，以及超过实际幅度的动作是否露出直底边。另有快速变化、连续点击、后台恢复、减少动态效果和原生窗口检查。
