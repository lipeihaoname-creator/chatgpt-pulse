# Windows 公开测试版复核

适用版本：0.16.6。此页是待执行清单，不代表已经通过。现有 Windows 11 本机结果及 0.16.5 历史基准见 [验收记录](WINDOWS_ACCEPTANCE.md)；已知缺口见 [发行准备](RELEASE_READINESS.md)。

## 下载完整性

在源码目录运行 `python scripts/verify-downloads.py --tag v0.16.6`。脚本通过公开 Release API 取得资产地址，下载两个 Windows EXE 与 SHA256SUMS，核对上传状态、文件大小、实际文件哈希和 API 提供的哈希，并检查文档直链。结果只说明下载完整性，不说明安装或运行成功。

## 干净系统和异机

在隔离虚拟机快照或专用测试机器上逐项执行。分别记录 Windows 10 x64、Windows 11 x64；当前没有 ARM64 安装器，不把 x64 编译当成 ARM64 验收。

| 检查 | 执行步骤 | 当前记录 |
|---|---|---|
| 缺少 WebView2，离线版 | 从未安装 WebView2 的快照开始，下载并校验完整包后断网，运行安装器；确认补齐运行时并正常启动 | 待执行 |
| 缺少 WebView2，联网版 | 恢复同一快照，联网运行小包；确认微软引导程序完成，应用正常启动 | 待执行 |
| 已有 WebView2 | 安装任一包，确认复用现有运行时；重复启动只保留一个正常应用进程 | 本机有记录，异机待执行 |
| 中文与空格路径 | 从资源管理器安装到中文含空格路径；验证打开、关闭到托盘、恢复和退出 | 0.16.5 有记录，0.16.6 待完整复测 |
| 升级 | 退出旧版后升级；确认版本、头像和设置保留 | 本机有记录，异机待执行 |
| 卸载与重装 | 使用合成设置验证默认保留数据；重装后确认设置恢复 | 0.16.5 有记录，0.16.6 待完整复测 |
| 无开发工具 | 在未安装 Node、Rust、Python、Visual Studio 的机器启动应用 | 本机精简 PATH 有记录，干净系统待执行 |
| Work 日志接入 | 先用隔离合成夹具验证无日志、首次接入、暂停和恢复；用户明确授权后再只读验证兼容本地 Work 日志 | 本机有记录，异机待执行 |

不要为测试而卸载日常电脑上的共享 WebView2 或关闭系统安全功能。未签名提示与哈希核对方法见 [安装说明](WINDOWS_INSTALL.md#下载与校验)。
