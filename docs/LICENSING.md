|---|---|
| 在自己的 Mac / Windows 上使用、学习、实验、修改代码 | 允许符合许可的用途；Windows 支持仍需另行完成 |
| 公司员工用 Pulse 监测自己的 Work / Codex 工作 | 内部使用附加许可明确允许，不按席位收费 |
| 自由职业者用 Pulse 辅助工作，再出售自己写的代码、设计或其他成果 | 允许；独立工作成果不等于 Pulse 本体 |
| 公司给内部人员及仅为其内部工作服务的外包人员部署或修改 Pulse | 允许，保留许可和署名通知，不向客户提供软件服务 |
| 非商业学习、研究、免费分享原版或修改版 | 按基础许可允许，须随副本保留条款与必需通知 |

| 面向客户收取 Pulse 功能的使用费、订阅费或托管服务费 | 不在当前授权范围内 |

## 署名、修改与再分发

分发项目覆盖代码或程序时，应同时附上完整 LICENSE（内含基础许可与附加许可）及 `Required Notice:` 通知。第三方许可、版权通知和源码提供义务也要保留。可以说明自己修改了哪些部分；改名或改外观不会消除原代码的许可条件。

没有要求用户出售的独立工作成果必须采用本项目许可。允许使用 Pulse 辅助内部办公，不等于允许把 Pulse 自身作为面向客户的付费产品或服务。额外商业用途需要相关权利人另行书面授权，本次没有授予该权限。

这些条款只覆盖许可方有权许可的项目代码及对应原创文字等，不授予角色、美术、参考图、商标或第三方软件的额外权利。麻衣与洛琪希素材的来源记录不等于分发授权，公开发行前仍需处理；见 [素材说明](ASSETS.md)。本轮没有因修改许可而删除或替换用户本机角色主题。
