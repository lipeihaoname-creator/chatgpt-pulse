# 2026-10-29 维护检查与仓库更新

本次在 Windows 0.18.2 选择性整合基础上继续检查。代码仍是音乐候选，不替换已有 v0.16.6 Release；原 Windows 0.18.2 安装器与本轮合并源码不同，不能宣称包含后来修复。

## 修复

- 周期采样尊重原生最小化状态；只有用户明确重新显示时才还原。
- Mac 正常退出不在界面线程等待可能查询窗口状态的音频线程。
- 启动联动与 `--watch-status` 同时识别 `desktop` 和 `musicpreview`。音乐候选已经运行时，不再因为只识别旧身份而重复尝试启动；仍保留用户手动退出后的锁存规则。
- 原生首轮用量验收从 package.json 获取版本，避免报告遗留固定旧版本。

## 验证

新增身份检测后，125 项 Mac Rust 测试通过，2 项真实输入用例默认忽略；84 项前端测试通过。完整界面、最终通用构建、原生生命周期和音频结果以本机本轮最终维护清单为准。GitHub 云端 Mac/Windows 构建结果以对应提交的实际检查为准，不用本机结果替代。

前一合并候选的真实音频验收包括 65 秒静音与恢复、随机音乐话题、音频开关/释放、隐藏/最小化/还原、正常退出；同时验证四任务共享一个头像的独立/合并气泡、30 秒后台监测及贴边双重启恢复。本次启动检测修复没有改变频谱、人物素材或日志 Token 算法。两轮测试分别保留，不把历史结果冒充当前二进制结果。
