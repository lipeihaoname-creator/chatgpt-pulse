# ChatGPT Pulse 0.18.2：系统音频频谱与人物律动（候选草稿）

本次候选在 Mac 和 Windows 共用的 Work 日志监测基础上，增加系统播放音频可视化、空闲人物律动、音乐话题与外观方案。

- 六种频谱：贴近横条、下缘半环、跳动光点、柔光曲线、镜像声柱、像素灯阵。
- 可调整配色、疏密、粗细、高度、响应、条带对比度、回落、透明度、峰值和对称布局；保存最多 12 个命名方案，支持文本/JSON 交换。
- 人物仅在成功扫描、没有未完成或异常任务时随音频轻动；工作、对话、拖动及勿扰优先。
- 音频默认关闭、用户启用，仅读取系统播放混音；不打开麦克风、不保存/上传音频，不增加 AI 请求。
- 兼容日志中的 Token 使用原上报与时间区间，不把没有上报写成零，也不伪装为实时解码速度。

## 安装资产

Mac 为通用 DMG（应用最低 13.3，音乐采集需要 14.2+），另提供同一应用 ZIP。Windows x64 默认完整离线安装器，联网版仅作为较小替代；音乐采集需要 Windows 10 1703+。普通用户不需要开发工具、Stereo Mix、虚拟声卡或 FFmpeg。发布时使用候选目录校验清单中的原始文件名，不覆盖旧 Release 或重新命名 Windows 交付包。

## 验证说明

Windows 交付机为 Windows 11 25H2 x64，真实 WASAPI、长静音恢复、原生 UI、隔离多任务和安装/升级/卸载保留数据有记录。Mac 已在选择性合并后重新构建与运行，按最终 `MAC_MERGED_VALIDATION.json` 列明实测结果。任何历史测试总数不替代当前平台验收。

Mac 仅本机 Apple Silicon 运行，Intel 仅构建；Windows 独立标准用户、Windows 10/异机、硬件切换及真正断网干净安装未验证。临时签名/未公证的 Mac 候选和未签名 Windows 安装器可能出现系统安全提示。

Mac 本机仍沿用音乐候选身份；早期桌面身份的数据和许可迁移未验证，公开前需确定身份及升级方案。因此此文案仍是本地候选草稿，不代表已经发布或所有升级路径已通过。
