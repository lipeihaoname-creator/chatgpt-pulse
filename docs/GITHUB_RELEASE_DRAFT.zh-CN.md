# ChatGPT Pulse 0.18.2 · 音乐律动公开测试版

新增系统播放音频频谱、空闲人物律动和随机音乐话题。六种频谱可调整样式、配色、疏密、粗细、起伏及响应，支持保存和分享外观方案；工作、点击互动、拖动和勿扰优先。音频默认关闭，仅在本机内存分析，不使用麦克风、不保存或上传声音，也不增加 AI 请求。Work 监测继续使用真实日志上报的 Token。

## 下载

- **Mac**：`ChatGPT-Pulse-0.18.2-mac-universal.dmg`，打开后拖入 Applications；ZIP 是同一应用的备份。
- **Windows x64**：优先选择 `ChatGPT-Pulse-0.18.2-windows-x64-music-offline-setup.exe`；`music-online-setup.exe` 为较小替代，缺少 WebView2 时需要联网。两个 EXE 只需安装一个。
- **源码**：`ChatGPT-Pulse-0.18.2-source.zip`；附件完整性见 `SHA256SUMS.txt`，构建来源见 `BUILD_PROVENANCE.json`。

应用无需 Node、Rust、Python 或开发环境。Mac 应用最低 macOS 13.3，音乐采集需 14.2+；Windows 音乐需 Windows 10 1703+。Mac 使用临时签名、未公证，Windows 安装器未签名，下载和首次运行仍可能出现安全提示；请核对来源和校验值，无需关闭系统安全功能。

## 升级

先退出旧 Pulse，再覆盖安装，无需删除数据库。**Mac 从 0.16.6 升级使用独立的音乐版设置身份，需要重新设置偏好和音频权限；旧版数据保留，不自动导入或删除。** 已使用音乐版的用户保留同身份设置与授权。Windows 按原目录升级。没有自动更新服务，需手动下载。0.16.6 Release 保留供回退。
