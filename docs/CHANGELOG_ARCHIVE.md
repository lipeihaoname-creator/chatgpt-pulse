# ChatGPT Pulse

新增害羞脸红、忍笑、鼓脸、困倦四种面部表情（两人各有睁眼/半闭眼/闭眼帧），空闲动作扩充至十三种；互动短句逐句配表情，共 216 句原创中文。设置页可直接预览，不必等待随机触发。状态变化采用约 240ms 缓动过渡，连续变化只保留最新目标，文字状态即时更新。

Mac 优先的本地性能仪表盘。Tauri 2 + Rust + Svelte + SQLite，代码为 MIT 许可（角色素材另见说明）。**0.15.0 使用 Codex / Work 本地事件与用量日志**，支持 Apple Silicon macOS；Windows 和 Chrome 尚未实现；已加入状态表情与轻量动画主题。

0.7.0 新增双布局、麻衣状态表情和个性化设置。此前整体自检与修复记录见 SELF_CHECK.md（内部历史报告，不随本次源码包分发）。0.6.1 修复设置覆盖、编辑隐藏后重现、来源切换竞争和日志原地重写等边界问题，保持原有悬浮条样式。

0.11.2 修复各悬浮窗渐隐与点击事件串扰；每个气泡只接收自己的任务数据。已跟踪或固定的会话即使退出最近 200 个文件列表也继续检查。编辑自动结束统一调度到界面线程。0.11.1 的长工具结果与日志追赶修复保留。

0.11.3 保留手动固定来源：日志或目录暂时不可读取时显示不可用、保留原选择，恢复后继续检查；刷新列表也不会改成其他来源。

0.11.4 减少鼠标静止时重复查询窗口几何；移动、按下/松开、编辑与设置变化仍立即处理。任务列表改称“未结束”，不把静默待确认说成持续工作。

0.11.5 保留暂不可读工作为异常气泡并自动接续；切换详情不再丢失其他旧工作或重建其气泡。运行中开启系统减少动态效果，也会停止表情过渡并完整显示当前短句。

## 空闲陪伴（0.15.0）

短暂悬停不再重置整轮等待；十三种小动作独立于表情与眨眼衔接，连续点击也能平滑回应。

确认没有未结束工作时，角色会偶尔主动说一句；点击头像可以接着聊两句。麻衣和洛琪希各有 36 组、每组 3 句原创互动，覆盖调侃、关心、休息、提问与日常小话题。默认每次随机等待约 1.5–4 分钟，可在偏好设置选择更安静或更活泼；不是固定周期，也不会在切回应用时补播。

空闲时另有微笑、好奇歪头、点头、轻摆和舒展，复用现有表情。新工作立即收起空闲互动并恢复工作表情；勿扰、动作开关和系统减少动态效果继续生效。主动聊天和动作可分别关闭，暂停监测或日志状态不明时不主动聊天。设置页预览不自动发话。详见 [空闲陪伴说明与角色参考](../IDLE_COMPANION.md)。

## 兔子与符文粒子（0.13.1）

移除方形状态饰品，改为头像外缘缓慢飘动的兔子轮廓（麻衣）与原创几何符文（洛琪希）。粒子错峰出现、沿曲线移动并淡入淡出，不遮挡脸部中心，也不接收鼠标事件。头像布局最多 6 个，紧凑悬浮条最多 3 个。延续状态小饰品开关；静默待确认、暂停、勿扰、关闭动效或系统减少动态效果时不播放。没有新增素材下载或运行时 AI 请求。

## 任务色签、快捷菜单与状态饰品（0.13.0）

每个任务自动使用稳定的色点/图形，布局切换不改变色签。在实时概览选择任务后，可填写、保存或清除「当前任务昵称」；昵称可选、仅存在本机，不读取聊天标题。

右键悬浮头像可打开原生快捷菜单：打开主面板、切换分开/合并、编辑或完成编辑、取消编辑、勿扰及暂停/继续监测。左键互动与拖动继续保留。

麻衣与洛琪希新增轻量状态饰品，两种布局均支持；推理、工具等活动使用不同装饰，完成装饰跟随短暂小剧场。关闭动效、勿扰、系统减少动态效果或状态待确认时不播放饰品。可在偏好设置关闭「状态小饰品」。自定义图片不额外覆盖角色装饰。

## 跟随人物的多任务气泡（0.12.0）

始终只显示一个人物。在「偏好设置 → 多任务显示」选择：

- **多个气泡 · 上下排列**（默认）：同列紧接主气泡排列，全部跟随人物一起拖动，左右贴边时整体向屏幕内侧展开。
- **一个气泡 · 分行显示**：同一个气泡按行显示各任务的状态、Token/s 和活动脉冲，不合并或相加速度。

去掉悬浮界面中的 `Work · …编号`，内部任务绑定和主面板来源详情保留。气泡处于同一个透明窗口，不再由各个窗口独立定位。位置一起保存，取消或 Esc 恢复整组原位置；无多任务时恢复原有紧凑外观。超出屏幕高度时限制窗口尺寸，可进入编辑模式滚动查看全部任务；锁定时继续鼠标穿透。

任务结束保留 12 秒结算，再收起对应项。头像保持一个，随后承接仍未结束的任务；固定主详情不改变其他气泡的任务绑定。保留角色、导入裁剪、动画、勿扰、启动联动、后台检查及暂不可读来源恢复。普通聊天监测仍已移除，不需要辅助功能授权。

## 洛琪希主题（0.11.0）

在「偏好设置 → 角色头像」选择 **洛琪希 · 状态表情**，可搭配新增的 **魔法书蓝**，也可保留原配色。与麻衣一样，内置九种状态表情、睁眼/半闭/闭眼过渡帧、轻微呼吸、点击短句与完成小剧场；全部本地运行。切换角色清掉旧短句，完成内容跟随当前角色，勿扰与系统减少动态效果继续生效。

基于用户提供的九张参考图和官方资料，采用便于圆形头像阅读的无帽造型；25 句教师风格短句为原创中文文案，不冒充原作台词。图片、语气研究和引用边界见 [ROXY_SOURCES.md](../ROXY_SOURCES.md)，完整内置工具生成提示词见 [素材说明](../src/assets/roxy/README.md)。麻衣、自定义图片与极简图标仍可随时切换。

## 头像与贴边个性化（0.8.0）

采用用户选定的猫耳人物与脉冲图标。0.8.1 已去掉图标的发光边框。气泡标题仅显示角色名，删除“同人互动”字样。

- **头像裁剪与缩放**：导入后可拖动调整脸部位置，支持 1–3 倍缩放、左右/上下控制、重置、取消；保存后同步主面板与悬浮窗。
- **贴边收纳**：头像气泡靠近屏幕左右边缘 24 逻辑像素内自动吸附；靠右时头像留在右侧，气泡向内展开。空闲 15 秒收起气泡，移到头像上恢复；新工作、回答/批准提醒和未知状态保持展开。

原有工作状态、Token/s、日志自动跟随、点击/拖动与编辑完成/取消功能保留。默认不记录聊天正文或性能历史。

## 导入与点击修复（0.7.2）

修复正式版 CSP 不允许临时 blob: 图片地址导致的导入解码失败，改为本地 data: 加载，保留原安全策略。支持 PNG/JPEG/WebP；导入成功后切到自定义头像并显示保存反馈，原生端验证并保存本地副本。取消不会覆盖当前头像，坏图片有明确报错。允许缺省 MIME 的支持格式；透明细节较多的图片按需进一步缩小，避免超过原生 PNG 大小限制。

修复头像点击被旧“拖动中”状态和 400 毫秒统一冷却吞掉。Mac 增加只针对本应用悬浮窗的 AppKit 鼠标事件监听，快速按下/松开也能识别，轮询仅用于补恢复；同一次事件通过序号去重，连续两次真实点击仍各自响应。保留位移、长按和松手位置检查，拖动不变成聊天。只观察本应用窗口，不需要新增辅助功能权限。

头像缓存失败后可重试，过期的异步图片响应不会盖掉新头像，销毁的视图也不会被迟到响应更新。主面板和悬浮窗继续用同一份已保存图片，不依赖原图片是否还在原位置。

头像气泡缩至 280×128 逻辑像素，悬浮条缩至 272×64；编辑模式只在底部增加按钮区。状态和 Token/s 靠近排列。点击人物出现本地短句，逐字显示，约 8 秒后收起，期间真实状态和速率仍保留；拖动不触发短句，也不产生任何监测事件。可以在偏好设置关闭互动。

增加半闭眼过渡图集、表情切换淡化和轻微回应动作，减少眨眼和表情硬切。动画关闭或系统减少动态效果时，不播放这些动作，直接显示完整句子。角色短句为研究声优访谈和语录情境后编写的原创同人文案，见 [调研与文案说明](../DIALOGUE_SOURCES.md)，不冒充原作字幕或 AI 实时回复。

## 个性化外观（0.7.0）

在“偏好设置 → 个性化外观”中选择轻盈悬浮条或头像气泡。麻衣主题含九种状态表情，眨眼、呼吸和可选星光/星环/柔光动效；支持关闭动效和系统减少动态效果。五种配色为薄荷抹茶、樱花奶霜、月光藤紫、冰川蓝和奶茶琥珀。自定义 PNG/JPEG/WebP 图片仅在本地缩小后保存，不上传；自定义静态图片不生成新表情。

头像外圈是近 40 秒真实活动脉冲，工作动效只在近期日志活动时出现。按需气泡会隐藏等候/暂停/结束后的内容，但始终保留需要回答、批准、未知和异常状态。圆形头像本身可直接拖动，编辑模式底部有“完成”“取消”，窗口随布局自动调整大小，靠近正文渐隐和鼠标穿透保留。设置中的表情选择器只操作合成预览，不改变实际监测。

精简悬浮显示在任务结束后保持当前速率 0，不把最终平均速率替代当前速率；主面板仍显示 12 秒结算卡。眨眼是装饰，不能作为工作证据。头像素材为内置 imagegen 生成的非官方同人表现，非原动画素材；[素材来源、提示词及许可范围](../src/assets/mai/README.md)与代码许可分开。

## 先看状态，再看速度

主面板和悬浮条以工作状态为主，显示任务计时、最后活动时间和最多 12 条事件轨迹。悬浮条默认只显示简短工作状态、Token/s 和活动脉冲，可开启累计输出；旧速率显示“上次”，报告年龄保留在悬停说明及主面板中。Token/s 保留为辅助指标；即使 Token 还没上报，推理、回复和工具事件也能确认有进展。监测范围是**已发现的兼容日志会话**；主详情展示所选的一项，气泡分别展示运行中的任务，不等于前台窗口或所有 GPT 聊天。

| 状态 | 含义 |
| --- | --- |
| 处理中 / 推理有进展 / 回复有更新 | 已记录开始、推理或回复事件，尚未收到结束事件；不表示可见逐 Token 流 |
| 工具处理中 | 工具调用已发出，仍有未匹配结果；支持并行调用，不读取命令、参数或结果内容 |
| 等待你批准 / 需要你回答 | 日志中明确出现批准或提问事件时才显示；本机近期日志未发现这些事件，不能保证每次真实等待都可识别 |
| 状态待确认 | 30 秒没有新活动记录，不能由此判定空闲、失败或卡死；看到新事件后自动恢复 |
| 本轮已完成 / 本轮已中止 | 仅在匹配的生命周期结束事件到达后确认 |
| 监测未更新 / 无法读取 / 状态未知 | Pulse 超过 5 秒没有检查结果，或日志缺失、损坏、时间无效；不能当作 GPT 空闲 |

动画只用于有近期进展的状态；等待你操作、静默、结束和监测中断时停止。每秒检查心跳仅代表 Pulse 在检查，和 GPT 是否工作分开显示。不推测完成百分比、剩余耗时或服务器负载。活动轨迹只存本次运行内存，不写 SQLite；首次读取的历史事件按其原始时间显示，不重播为新进展。

调研及信号边界见 MONITORING_DESIGN.md（内部历史设计记录）。

## 后台运行与三项增强（0.5.0）

- **后台同步**：原生线程采集不依赖主窗口；悬浮条在事件推送之外，每秒向本地原生端补取快照。隐藏后恢复显示会立即补取，旧的启动快照或暂停前的事件不能覆盖较新状态。悬浮条关闭 WebKit 后台节流（macOS 14+），监测期间使用允许系统睡眠的活动声明，暂停后释放；不防止电脑正常睡眠。
- **自动适应保留时间**：默认开启，读取当前任务最近最多 8 个有效正增量上报间隔；至少 3 个间隔后，以第 75 百分位的两倍作为候选值，并限制在用户设定的最低值与 120 秒之间。2 秒以下、120 秒以上和无效间隔不计入。依据实际事件时间，不根据每秒检查补造样本。可关闭自动模式，回到固定 15/30/60/120 秒策略。新任务重新学习，重复用量不参与。
- **活动脉冲条**：主面板与悬浮条都显示近 40 秒记录，每格 2 秒。只有实际开始、推理、回复、工具、用量增长、结束等事件点亮；检查心跳不计入。空格只是未见记录，不代表模型停止。最多保留 24 个非空时间格的汇总，只存内存。
- **完成结算卡**：监测期间新完成/中止的任务，短暂显示 12 秒输出、耗时和最终均速。标签明确为“本轮均速”，当前速率仍为 0；到时自动回到常态，新任务会立即收起，已有历史不触发。设置中可关闭。


## 使用

打开 `release/ChatGPT Pulse.app` 即会自动监测，默认每 1 秒检查一次日志并自动优先跟随运行中的 Work 会话。无需每次选文件或点击开始；没有日志时自动等待。上方“已检查 N 次”是实际读取心跳，用量事件年龄表示日志源的新鲜度；即使没有新 Token，检查仍在进行。

辅助指标“日志区间速率”按 **新增输出 Token ÷ 日志上报区间时长** 计算；首段从任务开始计时，后续从前一次新增输出事件计时，使用日志时间戳而非轮询间隔。区间不足 100 毫秒时保留计数并将速率标为未知，避免批量落盘的毫秒级尖峰。没有新用量时保持最近区间值，不随着时钟逐秒下降；超过 5 秒后转为 **上次报告**，同时显示原始上报年龄。只要仍有新的推理、回复或工具活动，继续保留旧区间值；默认以 **30 秒无新活动日志** 作为最低保留时间，自动模式会根据上报节奏延长至最多 120 秒；关闭自动后可选固定 15/30/60/120 秒。旧速率是最近已知值，不是当前吞吐；无活动到期后显示未知（—），不表示模型已停止。收到匹配的完成或中止事件后立即显示 **0 / 任务已结束**。最终任务均速单独留在详情、图表及可选历史中。日志仍会分批上报，区间值可能跳变；不作虚构插值或宣称瞬时解码速度。启动、恢复监测或首次切换日志时只建立基线，不把已有记录回放成当前速率。

自动检查最近 32 个候选及已跟踪会话（最多 64 项），按任务生命周期与真实活动选择，**不保证等同前台聊天**。多个任务并行时，暂停后关闭“自动跟随活跃日志”，选择要固定的会话并开始；固定选择会保存，下次启动沿用。暂停会停止检查，不会被内部轮询悄悄恢复。

### GPT 启动联动（macOS）

推荐将应用放在稳定位置。项目提供 `python3 scripts/install-mac.py --enable-watch`，复制已签名的 release 应用到 `~/Applications/ChatGPT Pulse.app`，再配置当前用户的启动联动。用户级启动项为 `~/Library/LaunchAgents/io.github.chatgptpulse.client-watch.plist`，无需管理员权限；没有修改 GPT、全局 shell 配置或系统级启动目录。

小型监听进程在登录后运行，约每 2 秒只检查 ChatGPT / Codex 进程是否存在；发现启动时在后台打开 Pulse。它不读取 GPT 窗口、输入或正文，不发送消息。已有 Pulse 不会重复打开；同一次 GPT 运行期间，用户手动退出 Pulse 后也不会反复拉起。GPT 完全退出再启动时会重新触发，极短的退出/重启若落在同一次检查间隔内可能无法观察到。

“偏好设置 → 随 GPT 启动”可启用或移除该用户级启动项；“打开 Pulse 后自动监测”可单独关闭。也可对安装后的应用执行 `Contents/MacOS/chatgpt-pulse --disable-client-watch`。应用移位置后应重新开关启动联动，以更新路径。macOS 若禁用了后台项目，设置中会显示未加载，需要在系统登录项中允许；启动项存在不等于已成功运行。

悬浮条左侧六点手柄在锁定时也可直接拖动；编辑模式可拖动整个内容区域，点击完成保存位置，取消或 Esc 恢复原位置；60 秒未移动自动完成。锁定时直接拖动的位置自动保存，重启恢复；保存位置离开当前屏幕范围时回到主屏。锁定后正文区域保持鼠标穿透，鼠标靠近正文约 220 ms 渐隐、移开淡入；靠近手柄、编辑或拖动时保持可见，避免越想拖动越消失。菜单栏可关闭。Mac 编辑快捷键是 Control + Option + Command + P，真实键盘及跨应用穿透仍待完整人工验收。关闭主窗口始终隐藏并继续后台监测，关闭菜单栏图标也不会改变这一行为；正常退出从应用菜单操作。

浏览器预览仅提供显式合成演示，不读取本地日志或更改启动项。日志模式无需辅助功能授权。不做字符换算。

## 计数和速度的口径

| 指标 | 来源与限制 |
| --- | --- |
| 任务输出 Token | `event_msg / token_count / info.total_token_usage.output_tokens` 在任务前后的累计差值，不逐行求和，不累加重复事件 |
| 其中推理用量 | `reasoning_output_tokens` 的任务差值；已包含于输出，不另行相加；不是推理正文 |
| 会话累计输出 / 推理 | 直接显示日志最后报告的累计值，即使任务基线缺失也可显示；不是费用账单或服务端独立核验 |
| 日志区间速率 | 新增输出 ÷ 日志上报区间秒数；有完整基线和有效递增时间才计算。超过 5 秒以“上次报告”及年龄标记保留值；连续无活动达到保留时长后显示 —（默认 30 秒），匹配结束事件立即归零。包含等待，受批量上报影响，不是瞬时生成速度 |
| 任务平均 Token/s | 仅当 `task_started` 与 `task_complete` 或 `turn_aborted` 的 `turn_id` 匹配、有任务基线、有用量事件及有效 `duration_ms` 时，任务输出 ÷ 任务耗时 |
| 任务耗时 | 日志报告的任务耗时，可能含推理、工具调用和等待，不是纯生成时间 |
| — | 未获取、没有基线、缺少匹配耗时、日志重置/损坏等；不冒充 0 |

事件可能延迟、批量更新。**区间速率和任务平均速率都不是实时解码吞吐量**。重复累计值和仅输入计数的变化不会延长保留时间；有效的推理/回复/工具活动可以延长显示，但不会修改速率原始时间；缺少基线、时间无效或日志损坏时速率显示 —，不可获取不冒充空闲 0。图表每个已结束任务只计一次，不按轮询次数重复画点。

输出用量可能包含不可见的生成内容；不能简单减去推理用量，就宣称得到精确聊天正文 Token。后台实际模型、服务端负载、首字延迟、可见正文的精确 Token 数仍不可获取。界面采集与旧字符估算代码均已删除。

日志依据本机实际格式验证；该内部格式不保证所有客户端版本一致。官方参考：[Codex App Server 用量事件](https://learn.chatgpt.com/docs/app-server)、[输出 Token 计数口径](https://developers.openai.com/api/docs/guides/token-counting#understand-output-token-counts)。

## 隐私与存储

只读 `~/.codex/sessions` 中自动跟随或手动固定的 `.jsonl`；拒绝路径越界和文件/子目录符号链接。列表只用生成文件名、修改时间，不读取聊天标题。按行识别事件，单次增量读取上限 8 MiB、记录缓冲上限 128 KiB；首次追赶历史在短时间预算内分块继续，不每块额外等待一秒；明确无关的长正文/工具记录直接跳过，无法识别的超长记录会使任务统计不可用。日志截断或替换会重建基线；累计计数下降会禁止该任务的差值和速率。

原日志可能包含正文，读取期间原始字节会短暂存在内存；Pulse 只提取允许的事件类型、数字用量、时间和生成标识，不将正文、标题、输入、推理正文、认证信息或原始解析错误传入界面、事件、SQLite 或其他输出。不会修改原日志，不调用额外 AI、收费 API，不发送聊天、不上传指标。

SQLite：`~/Library/Application Support/io.github.chatgptpulse.desktop/pulse.sqlite`。默认仅保存设置。启用“保留本地记录”后，仅保存监测期间**新结束**的任务时间、可用耗时、输出/推理计数、平均速率、完成/中止结果及会话/任务去重标识；不会导入已有任务或将暂停当作任务完成。保留期 1/7/30 天，自动清理；清空使用 secure_delete 与 VACUUM。旧版界面估算历史继续标记来源，绝不改标为日志数据。

## 项目与构建

- `src-tauri/src/background.rs`：监测活动保活，不阻止系统正常睡眠。
- `src-tauri/src/cadence.rs`：有界上报间隔统计、自适应保留。
- `src-tauri/src/activity.rs`：事件状态、并行工具匹配、活动轨迹与 30 秒静默判断。
- `src-tauri/src/logs.rs`：限域文件列表、增量读取、字段白名单、累计去重、任务匹配和结算。
- `src-tauri/src/store.rs`：设置与可选数字摘要，兼容旧版记录。
- `src-tauri/src/overlay.rs`：手柄命中、正文穿透、靠近渐隐滞回及 macOS 原生拖动。
- `src-tauri/src/follow.rs`：按日志写入时间选择、相同时间保持稳定。
- `src-tauri/src/startup.rs`：用户级启动联动、进程存在检查及可移除配置。
- `src-tauri/src/lib.rs`：应用命令、采集线程、菜单栏、快捷键与悬浮条。
- `src/`：仪表盘、悬浮条与浏览器合成演示。
- `VALIDATION.md`：实际验收范围；`LOG_SOURCE_FINDINGS.md`：来源核验。
- `LICENSE`、`THIRD_PARTY_NOTICES.txt`：项目与构建依赖许可，随应用打包。

构建需要 Rust、Node 和苹果命令行工具，不需要完整 Xcode。本次工具链和依赖缓存均置于项目 `.tools/`、`node_modules/`，未修改全局 shell 配置。依赖由 `pnpm-lock.yaml` 与 `src-tauri/Cargo.lock` 锁定。

```sh
sh scripts/build.sh
node --test tests/domain.test.mjs
cargo test --manifest-path src-tauri/Cargo.toml --lib
```

项目内工具环境可先加载 `scripts/env.sh`。`tests/browser.mjs` 使用已有 Playwright 和隔离 Chrome profile，不访问用户浏览器会话；`PULSE_PLAYWRIGHT_MODULE` 可指定模块路径。浏览器不能读取真实本地日志，只提供显式演示。

自动原生验证用 `PULSE_OFFLINE_TEST=1 PULSE_DATA_DIR=项目内测试目录`：此时日志根目录固定为该目录的 `logs/`，SQLite 也在测试目录，不接触真实会话或 AX。默认测试均使用合成数据。`local_metadata_check` 是默认忽略的检查，只有单独显式运行才只读本机日志并输出计数是否存在等白名单信息。

本机应用使用临时签名，未 Apple Developer 签名公证。跨机器分发、Windows/Chrome 兼容性尚未验收，没有向 GitHub 提交或公开发布。

macOS 机制参考：[Apple 用户级启动项](https://developer.apple.com/library/archive/documentation/MacOSX/Conceptual/BPSystemStartup/Chapters/CreatingLaunchdJobs.html)、[NSRunningApplication](https://developer.apple.com/documentation/appkit/nsrunningapplication)。
