# Mac 安装 · 0.16.6

下载 `ChatGPT-Pulse-0.16.6-mac-universal.dmg`，双击打开，将 **ChatGPT Pulse** 拖到 **Applications（应用程序）** 图标。复制完成后推出磁盘映像，从应用程序中启动。

也可将应用放到当前用户的 `~/Applications`，方便没有系统应用目录写入权限的用户。无需 Node、Rust、Python、VS Code 或完整 Xcode。不要长期直接从只读 DMG 中运行；启动联动应在复制完成后启用。

通用程序包含 Apple Silicon 和 Intel 架构，最低 macOS 13.3。本机 Apple Silicon 运行结果与 Intel 编译结果应分别看待；其他设备的验收范围见 [Mac 验收说明](MAC_ACCEPTANCE.md)。

## 首次打开

当前公开测试包使用临时签名，未做 Apple Developer ID 签名与公证。DMG 不是公证，也不会消除下载后的系统安全提示。若系统阻止启动，先核对文件来源与 SHA-256，再按 macOS 显示的“隐私与安全性”提示决定是否允许；具体流程见 [Apple 安全打开应用说明](https://support.apple.com/102445)。不要关闭 Gatekeeper、移除整机安全设置或执行来源不明的解锁命令。

## 监测

Pulse 读取当前用户的兼容 Work / Codex 本地日志，默认 `~/.codex/sessions`。已有绝对路径 `CODEX_HOME` 时，读取该根目录下的 `sessions`。无需额外模型调用、收费 API、辅助功能、屏幕录制或全磁盘访问权限。

正常 Work 产生兼容事件后自动跟随。普通 ChatGPT 聊天、浏览器聊天和没有兼容本地日志的云端工作不在支持范围内。没有用量上报时显示等待或未知；首次累计只建立区间起点，后续真实上报可计算区间速率，未知的任务总量不会被猜出。数据口径见 [DATA.md](DATA.md)。

关闭主窗口继续在后台监测；通过菜单栏或 `⌘Q` 退出。点击头像互动，按住拖动，右键或 `⌘⌃⌥P` 编辑，完成/取消均可退出编辑。可选的“随 GPT 启动”仅在 Mac 中提供，默认不替你开启系统启动项。

升级前正常退出旧版，再复制新应用；无需删除用户设置或数据库。卸载应用不会自动清除个人设置和可选数字摘要，删除个人数据应由用户明确选择。
