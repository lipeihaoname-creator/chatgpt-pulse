# Windows 安装与音乐律动

当前 Windows 音乐候选：0.18.2 x64。以随包 `WINDOWS_MUSIC_REPORT.md` 的实际验收范围为准；不是 GitHub 正式 Release。

## 选择安装器

- 默认完整离线版：`ChatGPT-Pulse-0.18.2-windows-x64-music-offline-setup.exe`，包含微软完整 WebView2 安装组件。
- 小体积联网版：`ChatGPT-Pulse-0.18.2-windows-x64-music-online-setup.exe`，缺少 WebView2 时需从微软联网补齐。

两版主程序相同，只需安装一种。安装面向当前用户，无需 Node、Rust、Python、Visual Studio、额外 SQLite、FFmpeg 或音频驱动。已有 WebView2 时复用；离线仅指安装依赖，无兼容本地日志的云端 Work 仍不受支持。

运行安装器，按向导安装。升级前退出旧 Pulse，再沿用原目录。设置、头像及可选摘要应保留；本版本新增的音乐开关默认关闭。没有自动更新服务，需要手动下载安装。当前候选未签名，可能显示发布者未知；核对来源与 SHA-256，无需关闭安全功能。

## 音乐

在侧栏“音乐律动”中，可先选择六种频谱、调整参数并管理命名方案，预览无需开启音频。启用“响应系统播放音频”后，程序跟随默认播放设备，在本机内存分析系统混音；不采集麦克风、不保存或上传音频。

音乐采集需要 Windows 10 1703 或更新系统。系统混音可能包含歌曲、视频、游戏与通话等声音；不识别曲名、歌词或情绪，受保护音频可能无法取得。曲线是频谱，镜像不表示独立双声道。没有声音时保持静音状态，恢复播放后自动响应；真正故障会说明状态并提供重试。

人物只在程序成功扫描日志、且扫描范围内没有未完成或异常任务时允许随音乐轻动。“没有检测到”不等于 GPT 已空闲。工作、推理、工具、待操作、多任务、点击/拖动/对话、勿扰与减少动态效果均优先。关闭音乐会释放采集资源；退出可使用托盘菜单。

## Work 与用量

默认发现当前用户 `.codex/sessions` 中的兼容日志，可通过 Pulse 进程的绝对 `CODEX_HOME` 指定位置。普通聊天、浏览器聊天和不生成兼容本地日志的云端 Work 暂不支持。

Token 直接来自日志，不估算、不额外派发模型任务。没有任务起始基线时明确显示“会话累计输出”，不把它当本轮用量；两次带有效时间的递增上报之间仍可计算区间速率。推理已包含在输出中。首次上报或有效区间尚未到达时显示等待，不表示零输出。

## 卸载与数据

使用 Windows“已安装的应用”或安装目录中的卸载器。默认保留用户数据；不要为了排查问题手动删除设置目录。安装器和源包不携带个人日志、凭据或设置数据库。

现有非商用许可与素材说明保持不变，完整文本和第三方许可随程序及源码提供。本轮没有自动向 GitHub 推送或发布。异机、物理音频设备切换和独立标准用户账户等未测项，以随包报告为准。
