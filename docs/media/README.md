# 实机演示素材

本目录供 README 和 [完整演示页](../DEMOS.md) 使用。所有界面来自 0.16.6 Mac 桌面应用的原生窗口采集；使用自带演示或隔离数值日志，不是真实性能测量。

PNG 为截图裁剪或等比例缩放；themes-macos.png 为六张原生设置预览的拼图；GIF 为原生截图帧编码，设置预览的片段进行了拼接。透明窗口在截图中以白底呈现。没有 AI 生成或补画产品界面，没有替换数字。

capture-manifest.json 记录每份成品的尺寸、帧数、SHA-256 和应用二进制摘要。不包含本机用户名、目录、聊天或账号信息。角色相关素材的原有权利边界见 [ASSETS.md](../ASSETS.md)，本目录不额外授予角色权利。
