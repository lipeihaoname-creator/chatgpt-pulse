# Windows 0.16.6 交付复查

日期：2026-10-25（Asia/Shanghai）。0.16.6 修复真实长任务中新日志缺少起始基线时，整轮区间速率被错误隐藏的问题。以下 0.16.5 平台验收记录保留为历史基准，不能当作 0.16.6 所有安装流程已重新执行的证据。

## 问题与修复口径

用户报告上一轮约 11 分钟的任务只有状态、没有 Token 速度。只读核查显示，该轮持续约 11 分 25 秒，共有 9 次真实用量上报，首次上报延迟约 212 秒。日志缺少任务开始前的累计基线，旧代码因此把整轮速率屏蔽；头像设置又关闭了累计输出显示。

新版将整轮总量与局部区间分开：第一条累计记录只建立区间起点；从第二条带有效时间、递增的累计记录起，计算两次报告之间的区间速率。整轮输出总量、推理量和整轮平均仍保持未知，会话累计值继续明确标识，不估算、不额外调用模型。

主窗口和悬浮窗对暂不可算的速率显示“等待上报”等具体原因。最初无上报的约 3 分半仍不能产生真实数字；两次上报之间的速率也不是模型逐秒解码速度。

## 本版验证记录

- 新增两项回归先在旧代码失败，再在修复后通过，覆盖缺失起点但后续区间有效、首次上报锚点、缺失时间、计数重置以及结束时不伪造整轮总量。
- 原生逻辑 105 项通过，0 失败，2 项需明确提供本地数据的检查默认忽略；其中实际数字元数据回放已单独执行通过。
- 将上述 9 条真实用量记录去除会话标识和正文后，经相同原生解析器回放，验证 8 段区间速率，整轮总量仍未知。没有额外制造模型任务。
- 前端逻辑 56 通过、0 失败、1 项 sh 测试跳过。

本版最终复查：27 套生产界面回归在同一次全量运行通过；四种原生布局、中文数据目录首次接入恢复以及没有整轮基线的原生首次用量场景全部通过。实际安装的 0.16.6 已读取当前真实 Work 的状态、输出与推理 Token；一次界面观测输出 32226、其中推理 10832，仅是日志快照。默认离线版从 0.16.5 升级成功，移除开发工具 PATH 后实际界面仍工作；联网版同版覆盖安装成功，主程序哈希匹配且用户设置数据库哈希不变。本版没有重新执行卸载/中文安装路径的安装器全流程；相关平台基准沿用下面明确标注的 0.16.5 历史验收。

两种安装器主程序完全相同；新包完整离线版约 226.46 MiB、联网版约 20.62 MiB。微软完整运行时与前轮同一 SHA-256，Microsoft 有效签名已重新核对。

本版仍未进行 Windows 10、异机或缺少 WebView2 的干净系统验收。当前未签名、素材授权及源码公开许可边界沿用 [发行准备](RELEASE_READINESS.md)。

# Windows 0.16.5 交付验收

日期：2026-10-25（Asia/Shanghai）。本机 Windows 11 家庭中文版 10.0.26200，x64，已有 WebView2。目标为 Windows 10/11 x64；ARM64 未构建。没有可用的第二台电脑或干净 Windows 虚拟机，本报告不冒充异机实测或零缺陷承诺。

## 本轮修复

- 复现 0.16.4 重复启动后存在两个正常进程。新版采用会话内单实例保护，重复点击只通知原进程恢复窗口。
- 隐藏或最小化后的恢复由原进程的窗口事件循环执行；已验证从隐藏启动的第二个进程也能恢复主窗口。
- 复现数据目录不可创建时初始化直接异常退出。新版明确显示本地错误说明、提示保留用户数据，并以退出码 1 结束。
- 设置数据库允许短暂占用等待，减少启动或保存时偶发文件占用失败。

## 两种安装包

- 默认完整离线版：226.53 MiB，内含微软完整 x64 WebView2 安装组件。
- 小体积联网版：20.69 MiB，内含微软联网引导程序，已有运行时时无需下载。

两版主程序完全相同。实际嵌入的微软组件已验证 Microsoft Corporation 有效数字签名，SHA-256 已记录；未修改微软组件。本机已有 WebView2，因此“缺失运行时”的安装分支只核对了组件、配置和生成的安装脚本，尚未在缺少 WebView2 的干净系统执行。

安装测试在当前工作应用执行环境进行，Windows 对日常默认位置存在 Codex MSIX 本地缓存映射；中文项目测试目录也已独立验证。独立资源管理器安装、没有 Codex 的干净机器、Windows 10 和其他设备仍待实机复核。不会为测试而卸载本机共享运行时或修改系统安全设置。

## 数据与发行范围

仅支持能生成兼容本地日志的 Work / Codex；无兼容日志的云端 Work、普通聊天和浏览器聊天尚未支持。没有任务前基线时，任务输出保持未知，并明确显示日志报告的“会话累计输出”；不能当成精确本轮用量。

安装包没有付费代码签名，其他电脑可能提示发布者未知。代码仍为 PolyForm Noncommercial 加内部使用附加许可；角色素材公开分发授权尚未解决。未上传任何远程仓库。

源码按公开文件白名单打包，排除日志、数据库、账号配置、依赖目录、编译缓存与内部诊断材料，逐项比对内容并提供 SHA256SUMS。必要设置备份与旧版本交付包保留。详细数字证据与原始失败输出留在本地 test-results/evidence，不随源码包分发。
